# Task 31.8 — JSON API: report export downloads (PDF and text)

Parent spec: `2026-08-06-epic-31-architecture.md`. The renderers already have
the right shape: `pdf::render_*` are pure `report -> Vec<u8>`, and
`cli/report/text.rs::format_*` are pure `report -> String`.

## Endpoints

`GET /api/exports/{pnl|expenses|tax|cashflow|balance|flagged|register|k1}`
with `format=pdf|text` plus the same date/account params as the corresponding
31.5 report route (pair rule included).

Handler shape: fetch the report via the same data fn 31.5 uses → render:

- `format=pdf` → `pdf::render_*(report, company, date_range)`;
  `Content-Type: application/pdf`.
- `format=text` → `format_*` with the `with_header(company_name, ...)`
  wrapper; `Content-Type: text/plain; charset=utf-8`. ANSI is already dead in
  serve mode (31.3 sets `colored::control::set_override(false)`); add a
  regression test asserting no `\x1b` bytes in the body.
- Both set `Content-Disposition: attachment; filename="nigel-<report>-<range>.<ext>"`
  matching the CLI's default naming scheme (`default_text_path` /
  `dispatch_pdf` conventions) as closely as practical.
- Company name from `db::get_metadata(conn, "company_name")`, same as
  `cli/export.rs` does; date-range label built with the same logic — extract
  the small label helper from `cli/export.rs` rather than duplicating it.

## Feature gating

Without the `pdf` feature: text export fully works; `format=pdf` returns 501
`feature_disabled` with the same message text the CLI uses ("PDF export
requires the 'pdf' feature…"). The route module compiles in both
configurations (cfg on the pdf arm only).

## Not in scope

`report all` bulk export (browser downloads are per-report; the SPA offers
per-report buttons — 31.15), server-side file writing (`--output` semantics
stay CLI-only), print stylesheets (31.15).

## Tests

Per report: text export byte-equals the CLI text export for the same seeded
DB and period (modulo the CLI's file chmod concerns — compare content);
pdf export returns `%PDF` magic + non-trivial length with correct headers;
param validation shared with 31.5 behaves identically; no-pdf build returns
501 for pdf and 200 for text; locked DB → 423.
