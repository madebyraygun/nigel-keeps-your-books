# Task 31.14 — SPA: import screen

Parent spec: `2026-08-06-epic-31-architecture.md`. Front end for 31.7's
upload/preview/confirm pipeline.

## Flow (wizard, three visible stages on one screen)

1. **Select** — `wc-dropzone` (`@nigel/ui`: drag-and-drop + file picker,
   accept .csv/.xlsx/.xls, shows filename/size after selection) + account
   `wa-select` (from `/api/accounts`) + optional format override `wa-select`
   (built-in importer keys + saved profiles from `/api/csv-profiles` +
   "Generic CSV…" opening the mapping form: date/desc/amount column indexes,
   date format, optional save-as-profile name — mirrors the CLI flags).
2. **Preview** — on upload+preview success show detected/effective format,
   sample rows table (reuse `wc-register-table`'s row styling or a simpler
   `wc-sample-table`), counts (to-import / skipped / malformed), and the
   duplicate-file warning prominently when `duplicateFile` (confirm stays
   possible only for non-duplicate; a duplicate offers "this file was already
   imported" with no confirm — CLI parity: the import would be a no-op).
3. **Confirm** — runs confirm; result panel: imported, skipped, malformed,
   categorized, still-flagged counts, with a "Review N flagged" button →
   `#review`, and a note that a pre-import snapshot was taken.

## Behavior

- Errors at each stage inline (bad mapping 400 messages under the mapping
  form; unknown account etc. as toasts).
- Upload progress for large files (fetch with progress isn't portable —
  indeterminate spinner is acceptable; keep the seam: progress belongs to the
  ApiClient impl).
- After a successful confirm, dashboard/register data is stale — screens
  already refetch on enter (standard pattern); no global cache to invalidate.
- State resets cleanly for a second import without reload.

## Tests

Mock-client wizard walk: select→preview→confirm with counts rendered;
duplicate-file path blocks confirm; generic mapping payload carries columns +
saveProfile; failed preview surfaces message and allows re-selection.
Previews + axe for `wc-dropzone` (idle, dragover, selected, error) and the
result panel.
