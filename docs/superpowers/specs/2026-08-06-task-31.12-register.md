# Task 31.12 — SPA: register browser with inline editing

Parent spec: `2026-08-06-epic-31-architecture.md`. Web version of
`browser.rs` — the richest screen. Data: `/api/reports/register` (31.5),
edits via `PATCH /api/transactions/:id` (31.6). The TUI's search/filter logic
is client-side there and stays client-side here (the register endpoint has no
search param; do not add one).

## Layout & components (`@nigel/ui`)

- `wc-register-table` — the core. Column layout mirrors the TUI (date,
  description, category, vendor, amount, flag). Renders all fetched rows with
  native scrolling; register data for a filtered period is small enough that
  virtualization is not required — but row rendering must stay cheap (no
  per-row wa- components except during edit). Row selection follows DOM focus
  (`tabindex`, roving), `aria-selected`, flagged rows visibly marked.
- `wc-register-toolbar` — account filter (`wa-select` fed by `/api/accounts`),
  date-range controls (year/month pagers reusing 31.15's `wc-period-nav` if
  landed first; else own it here and 31.15 reuses), incremental search box.
- Inline editing: on Enter/dblclick a row swaps category (searchable
  `wa-select` over `/api/categories`) and vendor (`wa-input`) cells into edit
  mode; Enter commits (PATCH, update row in place, toast on failure with
  rollback), Esc cancels. `f` (and a flag toggle button) PATCHes `flag`.
- Incremental search: case-insensitive across description/vendor/category
  (reimplement `recompute_search_matches` semantics), filtering the table live
  with a match count.

## Behavior parity

- Initial load: no date filter (all transactions) and auto-scroll so today's
  nearest row is in view (`scroll_to_today` parity; rows come date-ASC).
- Keyboard: ↑/↓ move selection, Enter edit, Esc cancel, PgUp/PgDn, Home/End.
  Document in a help tooltip.
- Running total footer matches `RegisterReport.total`.

## Tests

Component: table renders fixture rows, selection + keyboard nav, edit
commit/cancel event contracts, flag toggle; previews for default/dense/empty/
editing/flagged states + axe. App: search semantics vs a fixture set
(matching the TUI's case-insensitive contract), PATCH payloads via mock
client, failed PATCH rolls back and toasts, scroll-to-today picks the right
row for fixtures spanning today.
