# Task 31.3 — nigel serve: axum skeleton, embedded static hosting, localhost security

Parent spec: `2026-08-06-epic-31-architecture.md` (security model + crate
layout sections are normative here).

**Objective:** the `serve` subcommand, the `src/server/` module skeleton, the
security middleware, embedded static hosting, and graceful shutdown. Data
endpoints come later (31.4–31.8) — this task mounts `/api` with just a
placeholder `GET /api/ping`.

## CLI surface

`nigel serve [--port 5731] [--no-open]`. Clap variant in `Commands`; dispatch
pre-flight mirrors the dashboard's: init check (`NotInitialized` if no DB),
**no stdin password prompt** (serve is exempt from `needs_password` — the DB
unlocks via 31.4's endpoint), then open a connection and run `init_db`
(migrations) — for an encrypted DB this must be deferred until unlock, so run
migrations at startup only when `!is_encrypted(db_path)`; 31.4 runs them on
successful unlock.

## Server skeleton

- `serve` feature (default-on) gates deps: `axum`, `tokio`, `rust-embed`,
  `open`. Without it, `nigel serve` returns the same style of error the pdf
  gate uses.
- `src/server/mod.rs::run(port: u16, no_open: bool) -> Result<()>` builds a
  tokio runtime (serve is the only async entry point; main stays sync),
  binds `127.0.0.1:port` (report the actual port when 0), generates the
  session token, prints the tokenized URL, and opens the browser unless
  `--no-open`.
- Middleware order: Host/Origin check (403) → session cookie check (401,
  exempting `/auth` and static assets) → routes. Constant-time token compare.
  `/auth?token=` sets `nigel_session` (HttpOnly, SameSite=Strict, Path=/) and
  302s to `/`.
- Static hosting: `rust-embed` on `web/dist` with index.html fallback for
  non-`/api` paths. Until 31.9 lands, `web/dist/index.html` is a committed
  placeholder page — create it in this task so the embed macro has content.
- Graceful shutdown: `axum::serve(...).with_graceful_shutdown(ctrl_c)`.
- `colored::control::set_override(false)` at serve startup.
- `error.rs` defines `ApiError` (code/message/details) + `IntoResponse` with
  the epic's envelope and status mapping; `state.rs` defines `AppState`.

## Tests

- Unit: Host/Origin validator (accepts `localhost`/`127.0.0.1`/`[::1]` any
  port, rejects others incl. `evil.com` and IP-with-public-host), token
  compare, cookie parsing.
- Integration (tokio test with a bound ephemeral port, or tower `oneshot`):
  401 without cookie, 403 bad Host, 200 ping with cookie from `/auth`,
  static index served at `/`, unknown SPA path falls back to index, `/api/*`
  unknown path is JSON 404 (not the SPA fallback).
- Feature matrix builds: default, `--no-default-features`,
  `--no-default-features --features serve`.

## Out of scope

Locked-state semantics (31.4), any real data endpoint, the actual SPA (31.9),
and `docs/api.md` beyond a stub listing `/auth`, `/api/ping`.
