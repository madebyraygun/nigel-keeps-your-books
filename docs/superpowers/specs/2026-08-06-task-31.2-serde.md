# Task 31.2 — Derive serde Serialize on data-layer structs

Parent spec: `2026-08-06-epic-31-architecture.md`. Mechanical; wide surface.

**Objective:** every struct the API will return derives `Serialize` (and
`Deserialize` where it's an input), with `#[serde(rename_all = "camelCase")]`
as the epic-wide casing choice. No DTO layer.

## Inventory (from the code survey — add derives to exactly these)

- `reports.rs`: `PnlItem`, `PnlReport`, `ExpenseItem`, `VendorItem`,
  `ExpenseBreakdown`, `TaxItem`, `TaxSummary`, `CashflowMonth`,
  `CashflowReport`, `RegisterRow`, `RegisterReport`, `FlaggedTransaction`,
  `AccountBalance`, `BalanceReport`, `K1LineItem`, `K1OtherDeduction`,
  `K1Validation`, `K1PrepReport`, and `DateGranularity` (post-31.1 home).
- `reviewer.rs`: `FlaggedTxn`, `CategoryChoice`.
- `importer.rs`: `ImportResult`, `GenericCsvConfig` (+`Deserialize` — it's a
  request input), `ParsedRow` (in `models.rs`, appears in `ImportResult.sample`).
- `categorizer.rs`: `CategorizeResult`.
- `reconciler.rs`: `ReconcileResult`.
- `cli/accounts.rs` returns `models::Account`; `cli/categories.rs`:
  `CategoryRow`; `cli/undo.rs`: `LastImport`.
- `models.rs`: `Account`, `Category`, `Transaction`, `Rule`, `ImportRecord`,
  `ParsedRow` (all of them — cheap, and 31.5/31.6 will return several).
- `settings.rs::Settings` already has serde; leave field casing as-is on disk
  (settings.json is an existing file format — do **not** camelCase it; it is
  not an API struct. If 31.10's settings endpoints expose it, they wrap it).

Not derivable/not needed: `ImporterKind` (has `key()` string), `K1Mapping`
(internal), TUI structs, `RegisterBrowser`.

## Notes

- serde is already a dependency with `derive` — no Cargo.toml change.
- `rename_all = "camelCase"` goes on every struct above so JSON casing is
  uniform (AC #2); Rust field names are untouched.
- Smoke test: serialize a populated `PnlReport` (and one struct containing an
  `Option` + nested vec, e.g. `K1PrepReport`) with `serde_json::to_value` and
  assert key names are camelCase (`totalIncome`, `grossReceipts`, ...).
- `cargo test` with and without default features (gusto-gated structs must not
  break the no-default build).
